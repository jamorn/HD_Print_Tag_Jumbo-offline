🎨 HD Print Tag - Template System V2

ระบบ Template แบบใหม่ที่แยก Left/Right Section อย่างชัดเจน

📋 ไฟล์ที่สร้างใหม่

  • hd_report_v2.html - HTML หลักสำหรับแสดงผล
  • css/hd_report_v2.css - Stylesheet พร้อม Template positioning
  • js/hd_report_v2.js - JavaScript Engine สำหรับ Template System
  • test_template_v2.html - หน้านี้ (สำหรับทดสอบ)

🎯 Architecture Highlights

Right Section (Fixed)
ตำแหน่งและรูปแบบตายตัว:
• Grade
• Lot Number
• Net Weight
• Running Number
Left Section (Variable)
เปลี่ยนแปลงได้ตาม Template:
• Product Description
• MFG Logo
• QR Code
• Sirim Certification
Template System
แยก Configuration ชัดเจน:
• Template 1: Description Only
• Template 2: + Logos
• Template 3: + Full Certifications

🔧 How to Use

  1. กดปุ่ม "Setup Mock Data" เพื่อเตรียมข้อมูลทดสอบ
  2. กดปุ่ม "Open Template V2" เพื่อเปิดหน้า Print Preview
  3. ใช้ Dropdown ด้านบนซ้ายเพื่อเปลี่ยน Template
  4. กดปุ่ม "คำแนะนำการพิมพ์" เพื่อดูรายละเอียดและ Specs
  5. ทดสอบพิมพ์ด้วย Ctrl + P

💡 Key Features

  • ✅ แยก Section ชัดเจน: Right (Fixed) vs Left (Variable)
  • ✅ Template Configuration: แต่ละ Template มี Config Object แยก
  • ✅ CSS-based Positioning: ใช้ CSS Classes แทนการ hard-code
  • ✅ Easy to Extend: เพิ่ม Template ใหม่ได้ง่ายโดยเพิ่ม Config
  • ✅ Backward Compatible: ใช้ sessionStorage เหมือนเดิม
  • ✅ ไม่กระทบระบบเดิม: ไฟล์แยกอิสระทั้งหมด

⚠️ การต่อเชื่อมกับระบบเดิม

หากต้องการให้ระบบเดิม (index3.html) เปิด Template V2:

  1. แก้ไขปุ่ม "Print Preview" ใน formComponent_themed.js
  2. เปลี่ยน URL จาก hd_report.html เป็น hd_report_v2.html
  3. หรือเพิ่มปุ่มใหม่ "Template V2 Preview" ข้างๆ ปุ่มเดิม
