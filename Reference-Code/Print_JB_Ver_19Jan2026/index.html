Tag Printing System Guide

🎯 ขั้นตอนการใช้งาน

  1. 1 เลือก Unit - คลิก HDPE, PP, หรือ PPC ที่ navbar ด้านบน
  2. 2 เลือก Grade - คลิกที่ตารางเพื่อเลือก Grade
  3. 3 กรอกข้อมูล - Lot, หน้า, กะ, วันที่
  4. 4 Generate - คลิกปุ่ม "ยืนยันและแสดงตัวอย่างหน้าพิมพ์"
  5. 5 Print - กด Ctrl+P และตั้งค่า: Margins = None, Scale = 100%, Background graphics = เปิด
