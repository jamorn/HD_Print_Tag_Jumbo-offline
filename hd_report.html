📋 วิธีตั้งค่าการพิมพ์
🌐 Chrome / Microsoft Edge
กด Ctrl + P
คลิก "More settings"
Margin: เลือก "None"
Options: → "Headers and footers" → ยกเลิกเลือก
Background graphics → เลือก (เพื่อแสดงพื้นหลัง)
🦊 Firefox
กด Ctrl + P
คลิก "Page Setup"
แท็บ "Margins & Header/Footer"
ตั้งค่าทั้งหมดเป็น "--blank--"
Margins: ตั้งค่าทั้งหมดเป็น 0
⚠️ ข้อควรระวัง
ตรวจสอบให้แน่ใจว่าไม่มี header/footer ก่อนพิมพ์
เลือกขนาดกระดาษ A4 Landscape
ทดสอบพิมพ์ 1 แผ่นก่อนพิมพ์ทั้งหมด
📝 Grade / Product Name
⚖️ Net Weight
🔢 Running Number
📄 Product Description
